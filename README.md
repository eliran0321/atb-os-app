# ATB-OS: האפליקציות

המעטפות של ATB-OS לחנויות האפליקציות. המערכת עצמה היא אתר חי, והאפליקציה
פותחת אותו: אותם חשבונות, אותם נתונים, בלי קוד כפול.

- `ios/` - אפליקציית האייפון והאייפד (Capacitor סביב המערכת החיה).
- `www/` - הדף שמוצג כשאין חיבור לאינטרנט.
- `scripts/asc-setup.mjs` - הכנה חד-פעמית של החתימה מול אפל, בלי מק.
- `scripts/configure-ios.py` - ההתאמות של פרויקט האייפון אחרי `cap add ios`.
- `scripts/make-assets.mjs` - האייקון ומסך הפתיחה מנכסי המותג.
- `.github/workflows/ios.yml` - בנייה על macOS בענן והעלאה ל-TestFlight, בכל דחיפה ל-main.
- `.github/workflows/ios-check.yml` - בכל דחיפה לענף אחר: בדיקת קומפילציה בלי חתימה ובלי העלאה,
  והרצה בסימולטור של אייפון ושל אייפד שמצלמת את פתיחת האפליקציה (הקבצים של הריצה, `launch`:
  צילומים וסרטון). קוד חדש של המעטפת נדחף קודם לענף, ורק כשהבדיקה עוברת והצילומים נראים טוב
  הוא נכנס ל-main. `gh run download <מספר הריצה> -n launch` מוריד אותם.

אין כאן מפתחות, תעודות או סיסמאות: הם שמורים מחוץ לריפו וב-Secrets.
